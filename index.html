FACTIBILIDAD ECONÓMICA

La factibilidad económica consiste en determinar si un proyecto de software es viable desde el punto de vista financiero, evaluando los costos de desarrollo, implementación, operación y mantenimiento frente a los beneficios esperados.

Roger S. Pressman afirma que el estudio de factibilidad permite determinar si los beneficios que aportará un sistema justifican la inversión necesaria para su desarrollo, siendo una etapa esencial antes de iniciar un proyecto de software.

📊 Puntos de Función

Los Puntos de Función son una métrica utilizada en Ingeniería del Software para medir el tamaño funcional de un sistema desde la perspectiva del usuario.

Permiten estimar el esfuerzo, el tiempo y el costo del desarrollo a partir de las funciones que ofrece el sistema.
